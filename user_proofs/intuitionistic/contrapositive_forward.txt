Theorem: |- (P -> Q) -> (~Q -> ~P)

using deduction

Proof
1. |- P -> Q by Assumption
2. |- (P -> Q) -> ((P -> ~Q) -> ~P) by Negation Intro
3. |- (P -> ~Q) -> ~P by Modus Ponens: 1 2
4. |- ~Q -> (P -> ~Q) by Simp
5. |- ~Q -> ~P by applying hypothetical_syllogism (from minimal): 4 3
QED


This proof is also 19 lines in datalog, but above proof is more advantageous since if you ever apply contraposition, you'll get a cut proof
1. |- (P -> Q) -> ((P -> ~Q) -> ~P) by Negation Intro
2. |- ~Q -> (P -> ~Q) by Simp
3. |- (P -> Q) -> (~Q -> ~P) by weakening: 2 1
QED
