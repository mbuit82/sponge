Theorem: |- (P -> (Q -> (R -> (S -> x)))) -> (P -> (Q -> (R -> (y -> (S -> x)))))

Proof
1. |- (S -> x) -> (y -> (S -> x)) by Simp
2. |- (P -> (Q -> (R -> (S -> x)))) -> (P -> (Q -> (R -> (y -> (S -> x))))) by Strengthening: 1

IGNORE also works. ie, it strengthens the right amount
